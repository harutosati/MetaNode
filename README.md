# MetaNode

MetaNode enables real-time data processing and auto-scaling on a cloud-based, distributed service platform.

MetaNode is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- MetaNode enables real-time data processing
- and auto-scaling on a cloud-based,
- distributed service platform

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaNode.git`
2. `cd MetaNode`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
